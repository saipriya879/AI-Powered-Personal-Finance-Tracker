# 💰 AI-Powered Personal Finance Tracker

### Automated Transaction Management, Spending Analytics and AI-Powered Financial Insights

## 📌 Project Overview

The AI-Powered Personal Finance Tracker is a Python-based application designed to help individuals manage their income and expenses efficiently.

It allows users to record financial transactions, calculate their remaining balance, analyse spending patterns and receive AI-powered financial recommendations.

## 🎯 Problem Statement

Many individuals find it difficult to maintain financial records, understand their spending habits and identify opportunities to save money.

This project provides a simple solution by combining transaction management, data analysis and AI-powered insights in one application.

## 🚀 Key Features

- **Transaction Management:** Add, view and delete income and expense transactions.
- **Financial Summary:** Calculate total income, total expenses and remaining balance.
- **Spending Analysis:** Analyse expenses based on different categories.
- **High Expense Detection:** Identify transactions above ₹2,000.
- **Financial Profile Classification:** Classify spending behaviour based on financial activity.
- **Excel Integration:** Import and export financial transaction records.
- **AI-Powered Recommendations:** Generate personalised money-saving suggestions.
- **Interactive AI Assistant:** Ask financial questions and receive AI-generated responses.

## ⚙️ Technologies Used

- Python
- Pandas
- NumPy
- Excel
- Groq API
- Large Language Model (LLM) Integration

## 🔄 Project Workflow

**Stage 1: Transaction Management**
- Record income and expenses.
- Validate transaction details.
- Store financial records in Excel.

**Stage 2: Spending Analysis**
- Calculate financial summaries.
- Analyse category-wise expenses.
- Identify high-value transactions.

**Stage 3: AI-Powered Insights**
- Generate savings recommendations.
- Identify potential overspending.
- Provide interactive financial assistance.

## 📊 Sample Project Findings

Based on the sample dataset used in this project:

- Bills were the highest-spending category at ₹7,038.
- Rent was the second-highest category at ₹7,000.
- Bills and Rent together accounted for approximately 72.5% of total expenditure.
- The remaining balance was ₹1,630 from an income of ₹21,000.
